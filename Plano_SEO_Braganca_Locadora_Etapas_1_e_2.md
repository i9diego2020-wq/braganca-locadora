# Plano de Implementação SEO --- Bragança Locadora

## Etapas 1 e 2 --- Estrutura de páginas + Otimização SEO

**Site:** bragancalocadora.com.br\
**Objetivo:** ampliar a presença orgânica do site no Google para
pesquisas de locação de equipamentos, principalmente em Bragança
Paulista e região.

------------------------------------------------------------------------

# 1. OBJETIVO PRINCIPAL

Transformar o site em uma estrutura SEO baseada em:

-   Página inicial para termos institucionais e de categoria.
-   Página geral de equipamentos.
-   Páginas individuais para os equipamentos disponíveis.
-   Categorias de equipamentos.
-   Estrutura preparada para expansão posterior por cidade.
-   Titles, descriptions, H1, H2, URLs, textos, links internos, imagens
    e dados estruturados otimizados.
-   Preservação integral dos produtos que já existem no site.

## REGRA CRÍTICA --- NÃO REMOVER NADA

**NÃO remover, substituir, apagar ou desativar nenhum produto, página,
equipamento, imagem, conteúdo ou funcionalidade que já esteja cadastrado
no site.**

A lista enviada neste plano deve ser tratada como **novos equipamentos a
adicionar**.

Antes de criar qualquer produto:

1.  Verificar se o equipamento já existe.
2.  Se já existir, NÃO criar duplicado.
3.  Se existir com nome diferente, manter o cadastro existente e avaliar
    apenas a melhoria/associação SEO.
4.  Se não existir, adicionar como novo equipamento.
5.  Nenhum produto existente deve ser perdido durante a implementação.

# 21. CANONICAL

Cada produto deve possuir uma URL canônica única.

Exemplo:

``` html
<link rel="canonical" href="https://www.bragancalocadora.com.br/equipamentos/...">
```

Se o mesmo equipamento aparecer em várias categorias, todas as variações
devem apontar para a URL principal do produto.

Antes de inserir um equipamento:

``` text

- nome parcial
- modelo
- slug
```

# 29. PRÓXIMA FASE --- NÃO IMPLEMENTAR AGORA

Depois que o Search Console tiver dados suficientes, utilizar as
consultas reais para descobrir:

-   palavras em posição 4--10;

-   equipamentos que geram mais impressões;

apenas trocar o nome da cidade.
